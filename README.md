# MASAR | مسار — رفيق الطالب 🇴🇲

منصة عمانية لإنتاجية الطالب والتخطيط الذكي للدراسة.
إعداد وتصميم: معاذ بن عامر الشكيري (@mo3th.x)

## محتويات المجلد
| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع كاملاً (الصفحة + الأنماط + المنطق) |
| `manifest.json` | ملف PWA — يجعل الموقع يعمل كتطبيق على الهاتف |
| `icon.png` | أيقونة الموقع والتطبيق |

## خطوات النشر على GitHub Pages (بدون أي أوامر)

1. أنشئ حساباً مجانياً على [github.com](https://github.com) إن لم يكن لديك.
2. اضغط زر **+** أعلى اليمين ثم **New repository**، أعطه اسماً مثل `masar`، اجعله **Public**، واضغط **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file** (أو Add file → Upload files).
4. اسحب الملفات الثلاثة: `index.html` و `manifest.json` و `icon.png`، ثم اضغط **Commit changes**.
5. فعّل النشر: **Settings** → من القائمة الجانبية **Pages** → تحت Source اختر **Deploy from a branch** → الفرع `main` والمجلد `/ (root)` → **Save**.
6. انتظر دقيقة واحدة ثم حدّث الصفحة — ستجد رابط موقعك:
   `https://اسم-حسابك.github.io/masar/`
7. (اختياري) لتسريع ظهور الموقع في جوجل: سجّل الرابط في [Google Search Console](https://search.google.com/search-console).

## نظام الأعضاء والقائد 👑

- افتح الموقع واضغط مطولاً (1.5 ثانية) على شعار **مسار** (أعلى أو أسفل الصفحة)، أو اضغط عليه نقراً مزدوجاً مرتين متتاليتين.
- أدخل **الرمز السري للمالك** (الافتراضي: 76208 — يُنصح بتغييره من داخل الكود، السطر `const PIN=`).
- من تبويب **«الأعضاء»** يستطيع القائد:
  - إضافة عضو جديد → يحصل تلقائياً على رقم عضوية (M-001، M-002، ...).
  - تحديد كلمة مرور دخول للعضو.
  - تفعيل/تعطيل مميزاته: المساعد الذكي، الجدول، الصوتيات، الاشتراكات، سجل الدفع.
  - كتابة **جدول دراسي خاص** لكل عضو (كل سطر: `HH:MM | المادة | القاعة`).
  - التعديل (✏️) والحذف (🗑️) في أي وقت.
- عند دخول العضو ببريده وكلمة مروره: يرى **جدوله الخاص فقط** والمميزات التي حددها لها القائد.

## ⚠️ ملاحظة مهمة عن البيانات
الموقع يعمل بالكامل من جهة المتصفح (بدون خادم)، لذلك:
- بيانات الأعضاء والإعدادات تُحفظ في **localStorage الجهاز/المتصفح نفسه فقط** — أي أن الأعضاء الذين يضيفهم القائد محفوظون على **جهاز القائد**، وكل عضو يرى جدوله المخزّن على **جهازه هو**. البيانات **لا تنتقل بين الأجهزة تلقائياً**.
- صلاحيات العضو تُطبَّق على جهازه عند أول دخول؛ أي تعديل من القائد يحتاج آلية مزامنة (مثل Firebase) لتعمّم تلقائياً على كل الأجهزة.
- التخزين المحلي **ليس حماية أمنية قوية** — مناسب للعرض والاستخدام داخل مجموعة موثوقة. لحماية حقيقية وبيانات مشتركة بين الجميع يلزم ربط قاعدة بيانات خلفية (Backend).
